.env içine
APP_URL=https://example.com


Tamamen JSX bileşenleriyle hazırlanmış, statik olarak dışa aktarılan Next.js kurumsal web sitesi.

## Çalıştırma

```bash
npm install
npm run dev
```

Üretim build'i için:

```bash
npm run build
npm start
```

Build çıktısı `.next/` klasörüne yazılır ve site Next.js production server üzerinden çalışır. Sayfalar, hizmet detayları, sitemap ve robots route'ları build sırasında hazırlanır.

İletişim formu demo modundadır; veri göndermez. Telefon, e-posta ve WhatsApp bağlantıları doğrudan çalışır.
